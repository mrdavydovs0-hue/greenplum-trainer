# Changelog

Все заметные изменения сайта «Тренажёр Greenplum».

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по [семантическому версионированию](https://semver.org/lang/ru/):

- **MAJOR** — меняется структура курса (уровни, порядок, формат прогресса так, что старый прогресс не подходит);
- **MINOR** — новые разделы, схемы, интерактивы, задачи, вопросы;
- **PATCH** — исправления текста, ошибок, вёрстки.

Разделы внутри версии: **Добавлено**, **Изменено**, **Исправлено**, **Удалено**.

## [Не выпущено]

## [1.0.0] — 2026-10-14

### Добавлено
- Структура для GitHub Pages: сайт в `docs/` (`index.html`, `assets/style.css`, `assets/app.js`, `favicon.svg`, `.nojekyll`).
- README с инструкцией по локальному запуску и публикации, `.gitignore`, `.gitattributes`.
- Номер версии на стартовой странице.

### Изменено
- Сайт разделён из одного HTML-файла на разметку, стили и скрипт.

## [0.6.0] — 2026-10-14

### Добавлено
- Панель с иконками: тема (системная / светлая / тёмная), сброс прогресса с подтверждением, окно настроек с выбором темы и палитры.
- Уровень 2: анимация раздачи строк по сегментам по одной для BY / RANDOMLY / REPLICATED, схема «партиции × сегменты», таблица способов превратить хеш в номер сегмента, как узнать выбранный ключ распределения.
- Уровень 1: SQL под моделью кластера для каждого сценария, расшифровка имён хостов `mdw` / `smdw` / `sdw`.

### Изменено
- Пояснения про ключ распределения и необратимость хеша, заголовок над сегментами в калькуляторе хеша.

### Удалено
- Счётчики XP и серии из шапки.

### Исправлено
- Шаг «остаток от деления» в калькуляторе в одну строку, выравнивание кода в таблице политик.

## [0.5.0] — 2026-10-14

### Добавлено
- Разбор каждого неверного варианта в чекпоинтах, просмотр любого варианта после ответа, «Ответить заново», переход по вопросам.
- 9 задач на SQL с автопроверкой и эталонным решением (уровни 2–8).
- 8 палитр редакторов кода и переключатель темы.
- Расшифровки сокращений при первом упоминании и список сокращений.
- Уровень 1: словарь терминов, «Сколько сегментов в кластере». Уровень 2: хеш на примерах, интерактив трёх политик распределения, «Если не указать DISTRIBUTED».
- Блоки «как в psql» с подсветкой запроса и вывода.

### Изменено
- Все уровни: заголовок и связующий текст перед каждым блоком, текст на всю ширину, логичный порядок блоков.

## [0.4.0] — 2026-10-14

### Добавлено
- Теория из 21 карточки Anki и материалов gpskew.rzvde.pro.
- Уровень 1: что такое Greenplum, история, сравнение с PostgreSQL, плюсы и минусы, альтернативы.
- Уровень 2: калькулятор хеша, чек-лист ключа, коэффициент перекоса, JOIN трёх таблиц.
- Уровень 3: анимированная схема heap / AO row / AO column, VACUUM, индексы.
- Уровень 4: анимированный путь запроса, EXPLAIN ANALYZE, оптимизация, DISTINCT и GROUP BY.
- Уровень 5: схема «партиции × сегменты», виды партиционирования. Уровни 7–9: внешние таблицы, инструменты загрузки, вопросы с собеседований.

### Исправлено
- Модель JOIN: кнопки меняют DDL и раскладку строк.

## [0.3.0] — 2026-10-14

### Добавлено
- Уровень 1: схема кластера (мастер, standby, interconnect, хосты с primary и mirror).

## [0.2.0] — 2026-10-14

### Изменено
- Теория переписана по ошибкам первого прохождения: сегмент и партиция, JOIN и REPLICATED, хранение, Motion, границы партиций.
- Весь SQL — многострочными блоками с подсветкой, кнопка «Перечитать теорию» после ошибки.

## [0.1.0] — 2026-10-14

### Добавлено
- Первая версия тренажёра: 9 уровней теории с интерактивными моделями и чекпоинтами по материалам Stage 3.
